# AUTOGLASS 34 — сайт студии автостёкол и детейлинга (Волгоград)

Статичный сайт: HTML + CSS + JS, без сборки. Две темы (День / Ночь), заявки уходят Telegram-боту.

## Как выглядит и что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | вся страница: шапка, первый экран, услуги, цены, работы, «почему мы», заявка, контакты |
| `css/style.css` | стили; все цвета — токены в начале файла (ночь по умолчанию, `:root[data-theme="day"]` — день) |
| `js/glass.js` | главный герой: запотевшее лобовое стекло с каплями, курсор протирает, на телефоне идёт дворник |
| `js/main.js` | тема, шапка, карусель, форма, появление блоков |
| `js/config.js` | **ник Telegram** и телефон |
| `js/media.js` | **список фото и видео для карусели «Работы»** |
| `images/services/` | фото услуг (`01.jpg` … `06.jpg`) |
| `media/` | файлы карусели |
| `netlify/functions/submit.js` | принимает заявку и шлёт её боту в Telegram |
| `материалы/` | сюда можно складывать исходники; папка не попадает в GitHub |

## Что нужно вписать

1. **Ник Telegram** — в `js/config.js`: `telegram: 'ваш_ник'` (без @). После этого в шапке, в заявке, в контактах и на нижней панели телефона появятся кнопки Telegram, а если бот не ответит, форма откроет этот чат с готовым текстом заявки.
2. **Фото услуг** — `images/services/01.jpg` … `06.jpg` в порядке карточек: 01 тонировка, 02 замена стёкол, 03 ремонт сколов, 04 полировка фар, 05 полировка кузова, 06 расклейка тонировки. Сейчас есть 01–03; для 04–06 на карточках рисованные заглушки. Пропорция 4:3, кадр без текста, рамок и интерфейса телефона.
3. **Фото и видео для карусели** — положите файлы в `media/` и добавьте строки в `js/media.js` (пример в самом файле). Имена латиницей, видео `.mp4` (H.264). Пока список пуст, в разделе «Работы» показаны карточки-примеры.
4. **Цены** — в `index.html`, раздел «Цены» и цены на карточках услуг. Сейчас там прайс «от» с вашего прайса-картинки и цены на лобовое с установкой с autoglass34.ru; проверьте, что они актуальны.
5. **Часы работы** — в тексте их нет, их не было в источниках; добавьте в раздел «Контакты» (`index.html`).

## Заявки в Telegram

Форма шлёт `POST /.netlify/functions/submit`. Функция читает две переменные окружения:

- `BOT_TOKEN` — токен бота от @BotFather;
- `CHAT_ID` — id чата, куда приходят заявки.

Как подключить:
1. Создайте бота в @BotFather, скопируйте токен.
2. С аккаунта, куда должны приходить заявки, напишите боту `/start`.
3. В Netlify: Site configuration → Environment variables → добавьте `BOT_TOKEN` и `CHAT_ID`, потом Deploy заново.

Файл `.env` в папке проекта — шаблон для локальных заметок; он в `.gitignore` и в GitHub не попадает. Токен никуда, кроме `.env` и переменных Netlify, не вписывайте: репозиторий публичный.

Если функция недоступна (например, сайт на GitHub Pages), форма открывает ваш Telegram-чат с готовым текстом; если ник не задан — показывает телефон.

## Выкладка

Netlify через GitHub: репозиторий → Add new site → Import from Git. Сборка не нужна (Build command пустой, Publish directory — корень).

## Заметки по устройству

- Тема выбирается так: `?theme=day|night` в адресе → выбор посетителя (`localStorage['ag34-theme']`) → системная тема.
- Первый экран рисуется на canvas. При `prefers-reduced-motion` — один статичный кадр без анимации; вне экрана и на скрытой вкладке цикл стоит.
- Шрифты: Exo 2 (заголовки) и Onest (текст), подключаются с Google Fonts.
